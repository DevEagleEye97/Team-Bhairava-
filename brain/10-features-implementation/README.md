# Pillar 10: Features Implementation

**Domain:** Core User-Facing Modules & Operational Capabilities  

---

## 1. Study Room & Academic Repository (IA-1 Exclusive)
- **Scope:** Semester 1, P-Cycle, IA-1 course notes and question banks for Saptagiri NPS University.
- **Documents Included:** 17 verified PDFs across:
  - Problem Solving with C (PSC) Module 1 Notes, QPs, QBs.
  - Engineering Mathematics (MAT) Module 1 & 2 QBs, IA-1 QP.
  - Engineering Physics (PHY) Module 1 & 2 Question Banks.
  - Basic Electrical Engineering (BEE) IA-1 QP.
  - Design Thinking & IPR (DTI) Module 1 & 2 Question Bank.
  - Previous Years Question Papers (Comprehensive IA-1 bundles).
- **In-App Canvas Viewer:** Mozilla PDF.js canvas engine renders pages dynamically with zero plugin dependency.

---

## 2. Shvasa Pomodoro Focus OS
- **URL:** `https://shvasa.lovable.app/`
- **Sidecar Architecture:** Embedded in a 390px–480px docked side panel on the right.
- **Zero-Toggle Philosophy:** Students never lose access to their document library while running focus sprints or breathwork routines.
- **Controls:** Direct reload, pop-out external link, and collapse/expand action.

## 3. Hackathon Team & Sprint Board
- **5-Stage Kanban Workflow:**
  `DISCUSSING` $\to$ `PLANNING` $\to$ `DOING` $\to$ `REVIEWING` $\to$ `COMPLETED`
- **Decision Records:** Team leads can approve or reject proposals before advancing to active sprint tasks.
